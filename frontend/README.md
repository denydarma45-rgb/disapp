# Disapp Frontend (Web Prototype)

Prototype web untuk Disapp — hybrid WhatsApp + Discord.

## Cara menjalankan

```bash
cd frontend
python3 -m http.server 8080
# buka http://localhost:8080
```

Atau buka `index.html` langsung di browser (butuh internet untuk Tailwind CDN + Google Fonts).

**Demo login:** username `alex_rivera`, password apa saja.

## Fitur UI

- Login & Register (username-based)
- Layout 3-panel (Server rail + Sidebar + Chat)
- Kirim pesan lokal
- Design system Obsidian Flux (dark)

Production frontend akan dibangun dengan **Flutter**.
